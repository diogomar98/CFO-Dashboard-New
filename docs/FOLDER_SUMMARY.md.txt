# CFO-restore-news-features — Folder Summary

> **What is this project?**  
> A **Streamlit-based Databricks App** called **A.R.C. | CFO Command Center** — an AI-native morning cockpit for a fictional European universal bank's CFO. It combines synthetic financial data, live news intelligence, scenario modelling, peer benchmarking, and strategic M&A analysis into a single decision-support environment.

## 2. Where Is the Data Generated?

All data is **synthetic** and generated by scripts in `src/generators/`. The master script is `generate_all_data.py`, which produces **12 CSV files** in the `data/` folder in this dependency order:

```
bank_history.csv  (core monthly, 48 months)
├──> bank_daily_signals.csv      (daily granular signals, Jan–Aug 2026)
│      └──> news_signals.csv     (external news articles + impact scoring)
│           └──> news_geo_impact.csv  (per-country news impact)
└──> treasury_portfolio.csv      (52-position fixed income portfolio)
     ├──> treasury_scenario_impacts.csv  (rate/credit stress scenarios)
     └──> treasury_hedge_options.csv     (DV01-reducing hedge alternatives)

peer_financials.csv              (independent — real public FY2025 peer data)
├──> peer_positioning.csv        (return × capital positioning matrix)
└──> peer_benchmarks.csv         (summary stats: min/median/max)

strategic_radar.csv              (independent — synthetic M&A targets)
└──> strategic_capability_map.csv (capability gaps & linked companies)
```

## 3. Where Are Calculations Applied?

The app uses a **layered architecture** where calculations are clearly separated from presentation:

### Layer 1: Raw Data Generation (`src/data_generator.py`)
- Generates the core `bank_history` with a numpy-based random walk simulation
- Models: ECB rate cycle, loan/deposit growth, IFRS 9 provisions, capital adequacy, P&L

### Layer 2: Financial Metrics (`src/metrics.py`)
Calculates derived ratios from raw data:
- **Capital adequacy**: CET1 ratio, Tier 1 ratio, Total capital ratio, Leverage ratio, RWA density
- **Liquidity**: LCR, Loan-to-deposit ratio, Deposit growth (MoM/YoY)
- **Earnings**: NIM, Cost-to-income ratio, Pre-tax profit margin
- **Asset quality**: Stage 3 ratio, Coverage ratio, Cost of risk (bps)

### Layer 3: Certified Views (`src/cockpit_views.py`)
Pandas ports of SQL certified views. This is the **source of truth** for all cockpit numbers:
- `cfo_financial_history()` — full monthly time series with all ratios
- `cfo_current_position()` — latest month-end + year-to-date aggregates (ROE proxy, cost/income, YTD NII)
- `cfo_daily_bank()` / `cfo_daily_country()` / `cfo_daily_business_country()` — daily signal slicing
- `cfo_deposit_signals()` — deposit balances and 1d/7d/30d changes
- `cfo_credit_signals()` — IFRS 9 stage shares, credit watch flags
- `cfo_monthly_nim()` — monthly NIM and NII
- `cfo_news_intelligence()` — news articles with bank impact scoring
- `cfo_treasury_summary()` — portfolio book/market value, DV01, duration
- `cfo_peer_benchmark()` / `cfo_peer_benchmarks()` — peer comparison
- `cfo_strategic_radar()` / `cfo_capability_gaps()` — M&A and capability gap analysis

### Layer 4: Decision Engines (`src/engines.py`)
Two deterministic engines anchored on certified actuals:
- **Horizon Baseline**: momentum-decay NIM projection through year-end. Uses 50% repricing carry that halves each month.
- **What-If Engine**: governed balance-sheet shock simulation. Takes ECB rate shock, deposit balance shock, loan/deposit pass-through betas, replacement funding rate, and horizon days.

### Layer 5: Derived Cockpit State (`src/cockpit_state.py`)
One-pass computation that assembles every value the UI renders:
- Headline KPI ratios and their MoM deltas
- 30-day deposit/credit change signals
- RAG (Red/Amber/Green) status for every metric
- Narrative strings (why / impact / next step) for each KPI
- Confidence scores and tolerance bands
- Chart data slices

### Layer 6: News Signal Extraction (`src/news_partner.py`)
- Uses OpenAI to extract quantitative financial signals from news articles
- Signals map to What-If engine parameters: `rate_shock_bps`, `deposit_outflow_pct`, `stage_2_increase_pct_points`, `stage_3_increase_pct_points`
- Extracted signals can be pushed directly into the What-If Engine

## 4. Cockpit Modules (What Each Section Does)

| Module | File | Purpose |
| --- | --- | --- |
| **Morning Brief** | `modules/brief.py` | News feed (internal + external) alongside a domain grid showing every KPI with RAG status. NIM and deposit trend charts. |
| **Horizon** | `modules/horizon.py` | Deterministic NIM run-rate projection through year-end. Shows actual→baseline path with 90% confidence band. Can overlay news-derived rate signals. |
| **What-If Engine** | `modules/scenario.py` | Interactive balance-sheet shock simulator. User sets ECB shock, deposit shock, pass-through betas, horizon. Shows NIM and NII impact with confidence from beta sweep. |
| **Treasury Pulse** | `modules/treasury.py` | Portfolio market value, DV01, modified duration, +50bp impact. Market-risk scenario chart. Asset class composition and hedge options table. |
| **Peer Benchmarking** | `modules/peers.py` | ROE proxy vs peer median, CET1 comparison, cost/income ratio. Position matrix (return × capital scatter) and peer ledger table. |
| **Opportunity Radar** | `modules/strategy.py` | Strategic M&A radar with 7-factor scoring (strategic fit, financial attractiveness, integration feasibility, affordability, time to value). Capability gap analysis. |
| **News Intelligence** | `modules/news.py` | Full external news feed with per-article impact scoring. LLM-based signal extraction workbench. Actionable signals can be sent to What-If Engine. |
| **CFO Copilot** | `modules/copilot.py` | Conversational Q&A over cockpit data. Uses OpenAI (or deterministic fallback) for decision-partner thread. Genie-backed data Q&A thread via Databricks Genie Space. |
